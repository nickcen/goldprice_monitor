# 管理后台功能说明

返回[管理后台](ADMIN.md)。后台通过 API 服务读写数据，具体接口路径、请求与响应字段以 API 契约为准。

## 1. 登录与登录状态

- 管理员使用账号和密码登录；登录成功后保存服务端签发的 JWT，并在需要鉴权的请求中携带令牌。
- 进入后台时校验登录状态；令牌失效或接口返回未授权时，清除登录状态并返回登录页。
- 提供主动退出入口，退出时清除本地令牌和管理页面中的敏感数据。
- 服务端校验管理员身份和每项管理操作的权限；普通用户的 JWT 不得访问管理接口。

## 2. 用户管理

- 提供用户列表，展示用户 ID、手机号、等级、状态、有效期起止日期和创建时间；支持分页，以及按手机号或状态筛选。
- 点击用户进入详情页，展示该用户的基本信息和关联支付记录。支付记录按创建时间倒序分页展示，字段与支付记录管理列表一致；无记录时展示空状态。
- 支持修改指定用户的密码。提交时校验新密码和确认密码一致；服务端只保存密码哈希，不返回或展示原密码。
- 支持修改用户状态，状态取值为可用或不可用。变更成功后刷新列表中的状态。
- 支持修改用户有效期的开始和结束日期；允许单侧为空，若两侧均有值，结束日期必须晚于开始日期。开始日期包含当日，结束日期不包含当日；日期按 API 约定的 `YYYY-MM-DD` 格式传输，不做时区转换。
- 密码、状态或有效期修改失败时展示服务端错误，避免将未保存的值显示为已生效。

## 3. 支付记录管理

- 提供支付记录列表，展示支付记录 ID、用户、商品、系统支付单号、第三方支付单号、支付时间和创建时间；未支付或尚无第三方单号时显示为空状态。
- 支持分页，并按用户、系统支付单号、创建时间范围或支付时间范围查询；两个时间范围可同时使用，列表默认按创建时间倒序展示。
- 支付记录页面仅提供查询。支付状态、渠道、实付金额及退款信息等字段，待支付流程和数据模型确定后再补充。

## 4. 商品管理

- 提供商品列表，展示商品 ID、名称、价格、状态、排序值和创建时间；支持分页、按名称或状态筛选。默认按排序值升序、ID 升序展示。
- 支持查看商品详情，以及新增和编辑商品名称、价格、状态、排序值。价格以分为单位，必须为非负整数；状态取值为可用或不可用。
- 支持删除商品。删除前展示确认提示；若商品已关联支付记录，服务端应拒绝删除并提示改为停用，避免破坏历史记录的关联。
- 新增、编辑、删除成功后更新列表；失败时展示服务端错误。

## 接口与安全要求

- 登录、用户管理、支付记录查询和商品增删改查均由 API 服务提供接口，并执行参数校验与权限校验。
- JWT、密码和其他敏感信息不得写入日志；管理页面不展示密码哈希。
- 列表查询由服务端分页，避免一次加载全部记录；各页面提供加载、空数据和请求失败状态。
