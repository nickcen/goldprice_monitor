# 桌面端前端功能说明

返回[桌面应用](DESKTOP.md)。

## 登录后导航

- 登录或恢复会话后，左侧提供首页和账户菜单，右侧显示对应内容；首页默认展示当前金价与监控状态。
- 账户页展示当前用户配置，仅低价与高价提醒阈值可修改；用户等级、监控频率、金价 URL、币种、单位和精度只读。
- 切换页面不停止后台金价监控。

## 1. 注册

- 用户输入手机号、密码和确认密码。
- 前端校验手机号格式、密码必填，以及两次密码一致后提交注册请求。
- 注册成功后提示用户，并进入登录页面；注册失败时展示服务端返回的错误信息。

## 2. 登录与登录状态

- 用户使用手机号和密码登录。
- 登录成功后保存服务端签发的 JWT，并在需要鉴权的请求中携带令牌。
- 启动应用时恢复登录状态，并校验令牌是否仍有效。
- 令牌校验失败或鉴权接口返回未授权时，清除登录状态并自动退出到登录页面。

## 3. 登出

- 提供主动登出入口。登出时清除本地登录凭据、用户配置和正在运行的价格监控任务，并返回登录页面。

## 4. 获取用户配置

- 登录后获取并展示用户等级、监控频率、监控价格，以及金价数据的 URL 地址。
- 监控价格包括低价和高价；配置获取失败时展示错误状态，并允许重试。
- 以服务端配置为准；重新登录或配置更新后重新获取。

## 5. 定时刷新 JWT

- 登录后每小时刷新一次 JWT，并以新令牌更新本地登录状态。
- 应用从休眠中恢复时，检查刷新时间和令牌有效性，避免仅依赖定时器。
- 刷新失败时清除登录状态，停止价格监控，并自动退出到登录页面。

## 6. 价格监控设定

- 提供低价和高价输入项，允许用户分别设置监控阈值。
- 校验输入为有效的非负价格；两项均设置时，低价必须小于高价。
- 保存后提交服务端，并重新获取配置，使当前监控任务使用最新阈值。
- 金额单位、币种和精度与服务端金价数据保持一致。

## 7. 定时获取金价

- 根据用户配置中的监控频率和金价 URL 定时获取最新金价，并显示价格及最近一次成功更新时间。
- 登录后或配置变更后启动或重建定时任务；登出后停止任务。
- 请求失败时保留最近一次成功价格并显示获取失败状态；后续按监控频率继续尝试。
- 防止同一轮请求重叠；休眠恢复后重新检查配置和价格。

## 8. 桌面通知

- 当前金价高于设定的高价，或低于设定的低价时，发送包含当前金价和触发阈值的桌面通知。
- 在首批支持的 Windows 和 macOS 上通过 Tauri 桌面通知能力调用系统通知，并处理通知权限未授予或平台不支持的情况。
- 每次轮询获取的金价越过阈值时均发送通知；持续越界时按监控频率重复提醒。
- 未设置对应阈值时不触发该方向的通知。

## 9. 自动更新

- 应用启动时检查新版本，运行期间定期检查，并提供手动检查入口。
- 发现新版本时展示版本号、更新说明和下载进度；自动下载适配当前操作系统及架构的更新包。
- 下载完成后提示用户重启以安装更新；重启前保存必要状态，并在重启后恢复价格监控。
- 仅安装通过签名校验的更新包，更新地址和公钥由应用构建配置提供，使用 HTTPS 获取更新信息与安装包。
- 检查、下载或安装失败时保留当前可用版本，展示可重试的错误信息，不影响登录及价格监控。
- 分别验证 Windows 和 macOS 更新包的格式、签名和安装流程；不支持自动安装的情况应提示用户使用对应安装包手动更新。

## 10. 状态栏与系统托盘入口

- 应用启动后，在 macOS 菜单栏状态区、Windows 任务栏通知区域（系统托盘）显示应用 Logo 和当前金价；金价随定时获取结果更新，单位与主界面一致。
- 尚未登录或尚未取得金价时，显示 Logo 和明确的状态文字（如“未登录”或“获取中”）；获取失败时显示最近一次成功价格，并标明该价格并非最新数据。
- 点击状态栏或托盘入口，在图标附近弹出主界面。未登录时显示登录页面并提供注册入口；已登录时显示金价、监控状态和价格监控设定等操作。
- 每次点击入口都显示并聚焦主界面；只有点击窗口关闭按钮时隐藏窗口。隐藏后应用继续在后台按配置监控金价和发送通知。
- Windows 通知区域若无法在图标旁持续显示价格文字，应至少显示 Logo，并通过悬停提示展示当前价格及状态；点击行为与 macOS 保持一致。

## 接口与安全要求

- 注册、登录、令牌校验与刷新、登出、获取和更新用户配置均由 API 服务提供接口；具体路径及字段以 API 契约为准。
- JWT 等敏感凭据使用适合目标系统的安全存储方式，不写入普通配置文件或日志。
- 金价 URL 由 API 服务配置提供，可指向 API 服务或外部金价数据源；具体数据格式、鉴权方式和允许访问范围需在接口契约中明确。
